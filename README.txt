MUHAMMED ALI & SHIFANA THASNI — SCROLL-LINKED RINGS VERSION

The two gold rings are a fixed overlay linked to scroll progress:
- At the top, the rings start near the opening.
- As the visitor scrolls down, the rings move down with the page.
- Near the bottom, the rings slide together and interlock.

Includes the invitation, countdown, venue section, and couple image.
Keep index.html and the assets folder together when hosting. The standalone try HTML embeds the image so it can be opened as a single file.
